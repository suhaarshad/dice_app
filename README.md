🎲 **Dice Rolling App**
A lightweight and engaging Flutter app that mimics the experience of rolling a dice. It’s ideal for quick decisions, casual interaction, or as a beginner project to explore Flutter development.

📱 **Features**

* Tap to roll a digital dice
* Generates random numbers from 1 to 6
* Smooth rolling animation
* Simple, responsive, and clean interface
* Easy-to-understand code structure for beginners
